Guía rápida de uso

1. Información del Destinatario

Introduce el nombre y tratamiento de la persona a la que te diriges (p. ej., "Sra. Pérez"). Selecciona "Hombre" o "Mujer" para ajustar el saludo a "Estimado" o "Estimada".

2. Identificación del Técnico

Tu nombre se seleccionará automáticamente si has iniciado sesión. Este campo estará bloqueado y tu firma aparecerá en la vista previa.

3. Construcción de Bloques de Respuesta

Cada bloque representa una respuesta a un punto concreto.

  • Citar texto (opcional): Pega el fragmento del correo del usuario al que respondes para dar contexto.
  • Respuesta a este punto: Escribe tu respuesta específica.
  • Añadir/Eliminar: Usa el botón + Añadir bloque para añadir más respuestas o el icono de papelera para eliminarlas.

4. Copiar el Correo

Una vez estés satisfecho con la vista previa, usa los botones de copiado:

  • Copiar para pegar en email (Visual): Recomendado para la mayoría de casos. Copia el correo con todo su formato para pegarlo directamente en Gmail, Outlook, etc.
  • Copiar código HTML (Avanzado): Copia el código HTML puro para usos más específicos.

5. Consejos y Solución de Problemas

  • Firma automática: La aplicación detecta tu usuario de Google y asigna tu firma automáticamente. Si no aparece, prueba a recargar la página.
  • Privacidad: Los datos introducidos en este formulario no se guardan en ninguna base de datos, solo se procesan en tu navegador para generar la vista previa.
  • Reiniciar formulario: Para empezar un nuevo correo desde cero, simplemente recarga la página (F5).
